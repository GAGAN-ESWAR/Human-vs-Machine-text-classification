## 1. Executive Summary

This project addresses the challenge of identifying whether a sequence of tokens was authored by a human (`A`) or generated by a Large Language Model (`B`). All text in this dataset is anonymized/obfuscated into integer token IDs $\in [0, 18437]$ (where `0` denotes out-of-vocabulary / rare words). No raw text or external pre-trained LLM weights are accessible under competition constraints.

Through systematic iterations, we transitioned from standard lexical matching baselines to custom computational stylometry and probabilistic generative models:
1. **Initial Baselines (`train.py`)**: Token n-gram TF-IDF paired with linear models achieved **~90.19% CV accuracy**. Stylometry alone captured orthogonal signals, and stacking baselines into an out-of-fold meta-learner reached **~90.35%**.
2. **Extended Stylometry & Tuning (`tune.py`)**: Added positional head/tail stats, bigram entropy, hapax legomena rates, and automated threshold tuning.
3. **Generative & Topological Breakthrough (`train_generative.py`, `src/features_generative.py`)**: Introduced class-conditional 1st-order Markov transition log-likelihoods, Zipf's law rank-frequency decay, and spatial token burstiness. After solving a subtle target leakage problem via **Leave-One-Out (LOO)** smoothing, fusing these dense signals with 150,000 TF-IDF n-grams pushed performance to **92.61% CV accuracy** and **0.9772 ROC-AUC**.

## 3. Iterative Modeling Progression

### Phase 1: Core Baselines (`train.py`)

We established the 4 required project baselines in a modular architecture:

* **Baseline 1 (BL1) — Lexical Token N-Grams (1–3 grams)**:
  - Vectorized whitespace-joined token sequences into sublinear-scaled TF-IDF (capped at 150,000 features).
  - Classifiers: SAGA Logistic Regression ($C=1.0$) and Isotonically Calibrated LinearSVC ($C=0.1$).
  - *Result*: **90.19% CV Accuracy** (LogReg), **89.85% CV Accuracy** (SVC).

* **Baseline 2 (BL2) — Handcrafted Statistical Stylometry (10 features)**:
  - Extracted dense macro-statistical metrics: Document length, Unique token count, Type-Token Ratio (TTR), OOV rate (token 0), Shannon entropy of token frequency, Mean and standard deviation of token IDs, Repetition rate (adjacent identical tokens), Maximum run length, and zlib compression ratio.
  - Classifiers: LightGBM and XGBoost trained with `scale_pos_weight = 1.848`.
  - *Result*: Stylometry alone proved fast and captured orthogonal properties of document composition.

* **Baseline 3 (BL3) — Sparse-Dense Feature Fusion**:
  - Combined the 150k sparse TF-IDF n-grams horizontally (`scipy.sparse.hstack`) with the 10 dense stylometric features.
  - Classifier: LightGBM (`num_leaves=63`, `learning_rate=0.05`, `n_estimators=500`).
  - *Result*: **90.28% CV Accuracy**, improving discrimination over either feature set alone.

* **Baseline 4 (BL4) — Out-of-Fold Stacking Meta-Ensemble**:
  - Stacked the out-of-fold probability vectors from BL1-LogReg, BL1-SVC, BL2-LGBM, BL2-XGB, and BL3-Combined.
  - Meta-learner: L-BFGS Logistic Regression ($C=1.0$) trained with balanced class weights.
  - *Result*: **90.35% CV Accuracy**; successfully reduced model variance.

### Phase 2: Extended Stylometry & Hyperparameter Tuning (`tune.py`)

To prepare for the bonus mark controlled comparison study, we expanded stylometric features to 22 dimensions (`ExtendedStyleFeatures` in `src/features.py`):
- **Bigram Transition Dynamics**: Adjacent bigram Shannon entropy, unique bigram count, and bigram TTR.
- **Positional Signatures**: Mean token ID in opening 20 tokens vs. closing 20 tokens, and absolute head-tail divergence.
- **Frequency Concentration**: Top-1 relative frequency, top-5 cumulative frequency, and Hapax Legomena rate (fraction of singleton words).
- **Hyperparameter Optimization**: Conducted `RandomizedSearchCV` on LightGBM tree structures (`num_leaves`, `min_child_samples`, `colsample_bytree`, `subsample`, `reg_alpha`, `reg_lambda`).

---

### Phase 3: Generative & Topological Stylometry Breakthrough (`src/features_generative.py`, `train_generative.py`)

Rather than relying solely on count-based representations, we introduced probabilistic and structural features reflecting the underlying generative process of language models vs. human writing.

#### 1. The Features Engineered
1. **Class-Conditional 1st-Order Markov Log-Likelihoods ($LL_{\text{human}}, LL_{\text{ai}}$)**:
   - Evaluates the transition likelihood of consecutive token pairs $(t_{i-1}, t_i)$ under Human vs. Machine generative distributions:
     $$P(t_i \mid t_{i-1}) = \frac{\text{Count}(t_{i-1}, t_i) + \alpha}{\text{Count}(t_{i-1}) + \alpha \cdot |V|}$$
   - Because LLMs generate text by greedily or nucleus-sampling higher-probability transitions, human text exhibits distinct transition entropy drops and surprises.
2. **Zipf's Law Decay Slope ($\alpha_{\text{zipf}}$)**:
   - Fits the linear regression slope $\log(\text{frequency}) \sim \alpha \cdot \log(\text{rank})$. Machine text often deviates in tail rank decay compared to natural human syntax.
3. **Spatial Token Burstiness**:
   - Calculates the standard deviation of inter-arrival distances for recurring tokens ($\sigma_{\Delta \text{pos}}$). Human writing exhibits episodic "bursts" of topic words, whereas LLM text maintains smoother, more uniform token distributions.

#### 2. The Target Leakage Discovery & Fix
- **The Issue**: When first evaluated in cross-validation, the model accuracy dropped severely to ~71%. Investigation revealed that scoring a document using bigram transition counts that included that very document caused severe target leakage / overfitting. The model relied on memorized training counts that did not generalize to validation folds.
- **The Solution (Leave-One-Out Smoothing)**:
  We implemented exact Leave-One-Out (LOO) deduction during `fit_transform`. For each training sample, its own token counts were dynamically subtracted from the model parameters prior to scoring:
  ```python
  c_bi = max(0, c_bi - doc_bi.get((t1, t2), 0))
  c_uni = max(0, c_uni - doc_uni.get(t1, 0))
  ```
  This restored strictly unbiased out-of-fold scoring.

#### 3. Sparse-Dense Fusion & Results
- We fused the 150,000 TF-IDF n-grams with the 10 baseline stylometric features and the 4 dense generative features (`ll_human`, `ll_ai`, `zipf_slope`, `burstiness`).
- Running 5-fold Stratified CV with tuned LightGBM achieved:
  - **OOF Accuracy**: **92.61%** (a **+2.42% absolute boost** over the 90.19% baseline).
  - **ROC-AUC**: **0.9772**
  - **Optimal Decision Threshold**: $t = 0.52$

## 6. How to Reproduce & Submit

### 1. Reproducing the Best Model (92.61% CV)
To re-run 5-fold cross-validation and generate the final submission:
```bash
venv\Scripts\python train_generative.py
```
This will:
- Run 5-fold Stratified CV with `AdvancedCombinedFeatures` and tuned LightGBM.
- Find the empirical optimal decision threshold on out-of-fold probabilities.
- Re-fit on the complete 10,536 training examples and output a submission CSV to `submissions/`.

### 2. Reproducing the Baseline Comparison
To re-run all 4 course baselines:
```bash
venv\Scripts\python train.py
```

All submission files produced adhere strictly to the project rules:
- Exactly 3,001 rows (header + 3,000 data rows).
- Exactly two columns: `id, label`.
- Target values strictly $\in \{'A', 'B'\}$.
- ID alignment strictly identical to `sample_submission.csv`.
