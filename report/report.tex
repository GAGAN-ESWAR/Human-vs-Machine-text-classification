\begin{abstract}
This project investigates text classification from obfuscated token sequences using sparse lexical, stylometric, and sequence-structural features. Lacking raw semantic information, we engineered a 150,027-feature Champion representation combining TF-IDF n-grams, stylometrics, generative Markov log-likelihoods, and Heaps' Law dynamics. After identifying data leakage in the initial cross-validation pipeline, we implemented fold-isolated multi-seed validation, establishing a project-specific empirical 94.38\% hurdle for evaluating subsequent feature additions. The final experiments yielded two final ensemble configurations, both achieving 96.06\% public leaderboard accuracy. The Phase B LightGBM + Logistic Regression ensemble using the 150,028-feature similarity-augmented Champion representation achieved 94.43\% leak-free cross-validation accuracy, while the Phase 3 ensemble of standard and shallow LightGBM models achieved 94.46\%. Thus, both configurations produced the same public leaderboard result, with only a small 0.03 percentage-point difference in cross-validation accuracy.
\end{abstract}

\section{Problem and Data}
The objective is to classify whether a document was authored by a human (Class A) or generated by a machine (Class B). The training data contains 10,536 labelled documents, and the test data contains 3,000 documents. The task uses an unusual representation where all text is anonymized into sequences of integer token IDs drawn from a vocabulary of $V = 18,438$. Documents vary in length from a few tokens to just under 2,000 tokens.

This representation removes access to raw textual context and semantic word meaning because the token mapping is not distributed. Consequently, classification was approached using statistical, token-frequency, local-sequence, and transition-level information. The dataset exhibits class imbalance, with Class B occurring at approximately 1.85 times the frequency of Class A. Integer token sequences were used directly, and stratified folds were employed during cross-validation to preserve class proportions. The official competition metric is accuracy.

\section{Feature Engineering and Model}
To capture complementary signals from the integer sequences, four groups of features were engineered, resulting in a 150,027-dimensional representation:

\begin{itemize}
    \setlength{\itemsep}{1pt}
    \setlength{\parskip}{0pt}
    \setlength{\parsep}{0pt}
    \item \textbf{TF-IDF Representation (150,000 features):} Sublinear-scaled TF-IDF n-grams (1--3 grams). Designed to capture token-specific frequency and local sequence patterns.
    \item \textbf{Stylometric Features (18 features):} Includes document length, unique-token counts, and token entropy. Expected to capture broader document-composition characteristics independently of individual token identities.
    \item \textbf{Generative Markov Features (8 features):} Class-conditional sequence transition log-likelihoods. A dictionary-based mapping strategy was used for memory-efficient computation over the large vocabulary. This provides a compact summary of class-conditional transition behavior.
    \item \textbf{Heaps' Law (1 feature):} A vocabulary-growth exponent, capturing the rate of vocabulary growth with document length.
\end{itemize}

LightGBM formed the main base learner because the experimental pipeline could combine the sparse TF-IDF representation with dense engineered features while allowing nonlinear interactions among heterogeneous feature groups. Logistic Regression and a second shallow LightGBM were used in the two ensemble variants.

\section{Validation and Leakage}
Early modeling established an early TF-IDF + stylometric baseline of 89.82\% CV. Adding generative features substantially improved local performance to over 94\%. However, investigation identified data leakage: TF-IDF vocabulary construction and generative feature fitting had been performed globally before fold splitting. Therefore, validation folds improperly influenced feature construction, causing optimistic estimates.

The pipeline was corrected. Every feature transformation was fitted exclusively on the training fold and then applied to the validation fold, and subsequent evaluation used this leak-free protocol.

Using five-fold stratified cross-validation across five random seeds (42, 100, 2026, 777, 12345), the corrected baseline yielded accuracies of 94.02\%, 94.11\%, 94.15\%, 94.21\%, and 94.31\% (Mean = 94.16\%). To consistently assess subsequent additions, a project-specific empirical Mean + $2\sigma$ hurdle of 94.38\% was established (Figure~\ref{fig:multiseed}). This empirical threshold is not a formal statistical significance test and is not a guarantee of generalization.

\section{Experimental Comparison}
Several alternative hypotheses were evaluated using the leak-free protocol and empirical threshold (Table 1).

\textbf{Shape Statistics:} We hypothesized that token-shape or statistical characteristics might contain information not captured by token identity and n-gram frequency. However, this addition yielded a leak-free CV of 94.12\%, which did not exceed the 94.38\% empirical hurdle. The feature family was therefore not retained.

\textbf{Pseudo-labeling:} To test semi-supervised generalization, a configuration incorporating pseudo-labeling on high-confidence test predictions was evaluated. While it achieved a highly optimistic local CV accuracy of $\sim$95.00\%, its public leaderboard score dropped to 94.86\%. The discrepancy between local validation and public leaderboard performance is consistent with a possible self-reinforcing effect from pseudo-label errors, indicating that higher local validation performance did not necessarily translate into better public leaderboard performance.

\textbf{Similarity-Augmented Champion:} To investigate near-duplicate sequences, we added one dense feature capturing the maximum TF-IDF cosine similarity of each document to the training set. This configuration scored 95.93\% on the public leaderboard.

\textbf{Phase B Stacking:} A Phase B stacking ensemble was constructed using base models and a Logistic Regression meta-learner over out-of-fold predictions from the similarity-augmented 150,028-feature representation. This configuration achieved a leak-free CV of 94.43\% and a public leaderboard score of 96.06\%.

\textbf{Phase 3 Ensemble:} A Phase 3 ensemble combined two LightGBMs (one standard, one shallow) trained on the 150,028-feature representation. This configuration achieved a leak-free CV of 94.46\% and a public leaderboard score of 96.06\%.

\section{Discussion and Limitations}
TF-IDF n-grams preserve token identity and local sequence patterns. Markov likelihoods summarize class-conditional transition behavior. Heaps' Law captures vocabulary-growth behavior. Stylometrics summarize document-level composition. The similarity feature captures proximity to training documents. LightGBM combines these heterogeneous features and nonlinear interactions. Two final ensemble configurations---Phase B and Phase 3---achieved the highest observed public leaderboard accuracy of 96.06\%. The two configurations differed by 0.03 percentage points in leak-free CV accuracy (94.46\% versus 94.43\%). The 0.03 percentage-point difference is small relative to the observed multi-seed variability and does not by itself establish a meaningful difference. Furthermore, neither CV nor public LB performance proves that the models rely exclusively on general linguistic patterns rather than dataset-specific regularities.

\textbf{Training Accuracy and Capacity.} The full-capacity LightGBM reaches 100\% training accuracy. High training accuracy alone does not establish harmful overfitting; the relevant evidence comes from performance on held-out folds and independent leaderboard evaluation. In a diagnostic capacity experiment using a reduced 20k-TF-IDF + Heaps/Graph feature representation, the full-capacity LightGBM achieved 94.28\% validation accuracy, compared with 93.93\% for a regularized LightGBM, 93.55\% for a low-capacity LightGBM, and 91.84\% for a low-capacity XGBoost model. All tested lower-capacity configurations had lower validation accuracy than the full-capacity LightGBM in this diagnostic setup. However, this diagnostic does not prove that the model is completely free of dataset-specific memorization.

Limitations include a restricted hypothesis space and the fact that public leaderboard feedback inherently creates model-selection bias risk. The empirical 94.38\% hurdle is a pragmatic project-specific threshold, not a formal measure of statistical significance. The token mapping is unavailable, limiting semantic interpretation, and the fixed dataset limits claims about transfer to other sources or unseen generation systems. Finally, the 150k-dimensional sparse representation increases computational requirements.

\section{Conclusion}
This project engineered a 150,027-dimensional representation, and subsequently a 150,028-feature similarity-augmented representation, to classify obfuscated token sequences. Two final ensemble configurations (Phase B and Phase 3) achieved the same highest observed public leaderboard accuracy of 96.06\%. The small 0.03 percentage-point difference in cross-validation accuracy between them (94.46\% vs 94.43\%) does not establish that one is universally superior. More importantly, correcting early data leakage led to a robust fold-isolated, multi-seed evaluation protocol. This framework provided an empirical criterion for assessing features and demonstrated that higher local validation performance does not necessarily translate into better public leaderboard generalization. Capacity ablation showed that reducing capacity did not improve validation performance in the tested reduced-feature setup.
