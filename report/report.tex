\begin{abstract}
This project investigates text classification from obfuscated token sequences using sparse lexical, stylometric, and sequence-structural features. Lacking raw semantic information, we engineered a 150,027-dimensional representation combining TF-IDF n-grams, stylometrics, generative Markov log-likelihoods, and Heaps' Law dynamics. After identifying data leakage in the initial cross-validation pipeline, we implemented fold-isolated multi-seed validation, establishing an empirical 94.38\% threshold to rigorously evaluate subsequent feature additions. The final LightGBM and stacking configurations both achieved 96.00\% on the public leaderboard, while experiments demonstrated that higher local validation performance did not necessarily translate into improved public leaderboard generalization.
\end{abstract}

\section{Problem and Data}
The objective is to classify whether a document was authored by a human (Class A) or generated by a machine (Class B). The training data contains 10,536 labelled documents, and the test data contains 3,000 documents. The task uses an unusual representation where all text is anonymized into sequences of integer token IDs drawn from a vocabulary of $V = 18,438$. Documents vary in length from a few tokens to just under 2,000 tokens.

This representation removes access to raw textual context and semantic word meaning because the token mapping is not distributed. Consequently, classification must rely on complementary statistical and sequential representations: frequency, local token patterns, document-level statistics, and sequential transition structure. The dataset also exhibits class imbalance, with Class B occurring at approximately 1.85 times the frequency of Class A; this imbalance was accounted for during model development and evaluation. The official competition metric is classification accuracy.

\section{Feature Engineering and Model}
To capture complementary signals from the integer sequences, four groups of features were engineered, resulting in a 150,027-dimensional representation:

\begin{itemize}
    \setlength{\itemsep}{1pt}
    \setlength{\parskip}{0pt}
    \setlength{\parsep}{0pt}
    \item \textbf{TF-IDF Representation (150,000 features):} Sublinear-scaled TF-IDF n-grams (1--3 grams). Expected to capture token-specific frequency and local sequence patterns. Observed to provide the primary sparse signal for distinguishing class-specific token usage.
    \item \textbf{Stylometric Features (18 features):} Includes document length, unique-token counts, and token entropy. Expected to capture broader document-composition characteristics independently of individual token identities.
    \item \textbf{Generative Markov Features (8 features):} Class-conditional sequence transition log-likelihoods. Expected to capture sequential transition behavior and differences in how token sequences are generated. A dictionary-based mapping strategy was used for memory-efficient computation over the large vocabulary. Observed to provide a dense, highly discriminative summary of sequential transition probabilities.
    \item \textbf{Heaps' Law (1 feature):} A vocabulary-growth exponent. Expected to capture the rate at which new unique tokens appear as document length increases, reflecting lexical diversity.
\end{itemize}

The primary model is a LightGBM classifier. A tree-based model was selected because it efficiently handles the large sparse TF-IDF component alongside dense numerical engineered features, and naturally models nonlinear interactions among these heterogeneous feature groups.

\section{Validation and Leakage}
Early modeling established an initial baseline of 89.82\% CV using TF-IDF and stylometric features. Adding generative features substantially improved local performance to over 94\%. However, during this phase, investigation revealed data leakage: TF-IDF vocabulary construction and generative feature fitting were performed globally on the entire dataset before fold splitting. Consequently, information from validation folds improperly influenced the feature representation used during training, leading to optimistic validation estimates.

To correct this, a leak-free protocol was implemented: feature transformations were fitted exclusively on the training fold and then applied to the validation fold. This fold-isolated procedure eliminates data leakage and provides a more defensible estimate of generalization.

The corrected baseline LightGBM configuration was evaluated across five random seeds (42, 100, 2026, 777, 12345), yielding accuracies of 94.02\%, 94.11\%, 94.15\%, 94.21\%, and 94.31\% (Mean = 94.16\%). To rigorously assess future additions, a project-specific empirical Mean + $2\sigma$ hurdle of 94.38\% was established (Figure~\ref{fig:multiseed}). This empirical threshold provided a consistent criterion for deciding whether later feature additions meaningfully exceeded the variability observed across the baseline seeds; it is not a formal statistical significance test or a guarantee of generalization.

\section{Experimental Comparison}
Several alternative hypotheses were evaluated using the leak-free protocol and empirical threshold (Table 1).

\textbf{Shape Statistics:} We hypothesized that token-shape or statistical characteristics might contain information not captured by token identity and n-gram frequency. However, this addition yielded a leak-free CV of 94.12\%, which did not exceed the 94.38\% empirical hurdle. The evidence did not justify retaining the additional feature family, and it was rejected.

\textbf{Burstiness:} We hypothesized that burstiness could capture repeated or local concentration patterns in token usage that differ between human and machine-generated sequences. The observed leak-free CV of 94.21\% remained below the empirical hurdle, and it was not retained.

\textbf{Pseudo-labeling:} To test semi-supervised generalization, an ``ultimate'' configuration incorporating pseudo-labeling on high-confidence test predictions ($p > 0.98$ or $p < 0.02$) was evaluated. While it achieved a highly optimistic local CV accuracy of 95.00\%, its public leaderboard score dropped to 94.86\% (compared to the 96.00\% Champion). This severe discrepancy demonstrates that the pseudo-labeling procedure introduced a self-reinforcing bias, highlighting that higher local validation performance does not guarantee improved public leaderboard generalization.

\textbf{Stacking:} A Phase B stacking ensemble was constructed using LightGBM and Logistic Regression base models, combined via a Logistic Regression meta-learner with a final classification threshold of 0.45. Stacking increased leak-free CV from 94.16\% to 94.22\%, but public leaderboard performance remained at 96.00\%. Thus, it provided a small local validation improvement but no observed public-LB improvement.

\section{Discussion and Limitations}
The final feature families were introduced to capture orthogonal generative signals: TF-IDF for lexical frequency, stylometrics for macroscopic structure, and Markov features for local transitional probabilities. LightGBM was strictly chosen because it effectively models the nonlinear interactions between dense numerical features and the massive 150k sparse token distribution (Figure~\ref{fig:feat_imp}) without requiring imputation.

Shape statistics and burstiness were rejected because their empirical performance did not exceed the multi-seed noise floor, suggesting they added redundant information. Pseudo-labeling was rejected despite a higher local CV because it failed on the external public leaderboard, indicating that the semi-supervised mechanism likely amplified existing dataset biases rather than uncovering new signal. Similarly, stacking was not clearly superior; while it provided a negligible local CV gain (+0.06\%), it yielded no observable public leaderboard improvement over a single well-tuned LightGBM.

Several limitations constrain these results. First, the hypothesis space is limited and the final configuration is not mathematically proven to be optimal. Second, the 96.00\% performance relies entirely on the public portion of the test set; because public leaderboard feedback inherently risks selection-bias overfitting, it cannot be treated as definitive proof of generalization to the unseen private leaderboard. Finally, the empirical 94.38\% hurdle is a pragmatic project-specific threshold, not a formal measure of statistical significance.

\section{Conclusion}
This project demonstrates that combining sparse TF-IDF representations with stylometric and sequence-structural features produces a 150,027-dimensional representation that achieves 96.00\% public leaderboard accuracy with both single LightGBM and stacking configurations. 

More importantly, correcting data leakage caused by fitting feature transformations outside the validation folds led to a robust fold-isolated, multi-seed evaluation protocol. This framework provided an empirical criterion for assessing subsequent feature additions. The pseudo-labeling experiment explicitly demonstrated that a higher local validation score (95.00\%) did not necessarily translate into better public leaderboard performance (94.86\%). These results highlight the critical importance of leakage-free validation and independent evaluation when developing classification systems from obfuscated sequential data.
